# Captured saves

Place reviewed candidate `.ftgd` or `.ftgt` files here using the fixture ID as the stem. The same bytes and SHA-256 must be used by both VMs wherever compatible. Approved saves are immutable evidence: never open and resave one; create a versioned fixture.

These files use the legacy unsafe object serializer. Load only controlled VM-created fixtures or custody-approved historical saves, never untrusted input or a host/modern process.
